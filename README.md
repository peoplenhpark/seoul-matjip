# 🎯 서울 도심 만남 컨시어지

서울 4대문 안(광화문·서촌·북촌·삼청동·명동·을지로) 중심 **맛집 60곳 + 볼거리 26곳**을 묶어, 시간·동네·동행자만 고르면 3초 만에 맞춤 코스를 추천하는 PWA 앱. (현재 **v5.1**, 특화 중식은 연희·연남·여의도·대림 등 일부 포함)

## 📍 라이브
👉 **https://peoplenhpark.github.io/seoul-matjip/**

## ✨ 기능
- **🎯 컨시어지 위저드** — 시간·동네·동행자 입력 → 식당 + 볼거리 맞춤 코스 즉시 추천
- **맛집 60곳** 6개 카테고리 (양식·한식·일식·중식·동남아·유럽식)
- **볼거리 26곳** 5개 카테고리 (궁궐·문화재 / 한옥·골목 / 시장·쇼핑 / 박물관·미술관 / 공원·광장)
- **맛집 / 볼거리 탭** 전환 · 지도 + 핀 · 핀치 줌 · ⛶ 크게보기
- **방문 체크** 날짜·★평점·메모 기록 (localStorage)
- **🎲 룰렛** · **추천 코스 저장** · **➕ 내 맛집 추가**
- **빠른 실행** 📞 전화 · 🗺️ 카카오맵 · 📅 캐치테이블
- **영업 상태 뱃지** 🟢 영업 중 / ⏰ 30분 후 마감 / ⚫ 종료
- **PWA** 홈 화면 설치 · 오프라인 지원

## 🗂️ 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 루트 진입점 (redirect + OG 태그) |
| `seoul_restaurants.html` | 메인 앱 (맛집 60 + 볼거리 26 데이터 + 지도 + 컨시어지 위저드 + JS 전체) |
| `seoul_4daemun.html`, `seoul_4daemun.svg` | 📜 상세 지도 (도로명 압축지도, SVG, 별도 페이지) |
| `seoul_dosung.html`, `seoul_dosung.jpg` | 🏯 상세 지도 2 (한양도성 전도 — 순성길 코스, 이미지 뷰어) |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | Service Worker (오프라인 캐싱) |
| `icon.svg` | 앱 아이콘 (홈 화면) |
| `og-image.png` / `og-image.svg` | 카카오톡 공유 미리보기 이미지 |
| `og-png-convert.html` | OG 이미지 PNG 재생성 도구 (선택) |
